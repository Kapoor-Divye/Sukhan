# Sukhan

### Where thoughts find form.

Sukhan is a modern full-stack blogging platform built using React, Appwrite, Redux Toolkit, and Tailwind CSS.

It allows users to create, edit, and manage blogs with authentication, rich text editing, image upload support, and a clean responsive UI.

---

## Features

- User Authentication
- Create & Edit Blogs
- Rich Text Editor (TinyMCE)
- Image Upload Support
- Custom Fallback Blog Covers
- Protected Routes
- Responsive UI
- Appwrite Backend Integration
- Redux State Management
